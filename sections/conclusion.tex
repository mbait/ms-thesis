\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

В настоящей работе разработан физический движок \textit{dyphur}~---
библиотека симуляции твёрдых тел с GPU-ускорением на основе стандарта SYCL~2020.

В ходе работы решены следующие задачи:

\begin{enumerate}
  \item Проведён сравнительный анализ существующих систем физического моделирования
    (Bullet Physics, NVIDIA PhysX, MuJoCo, ODE, Rapier, NVIDIA Newton).
    Установлено, что ни одна из них не удовлетворяет совокупности требований:
    открытая лицензия, GPU-независимость от производителя, встраиваемый C++ API.

  \item Сформулированы функциональные и нефункциональные требования к разрабатываемой
    системе; обоснован выбор SYCL/AdaptiveCpp как GPU-стека,
    XPBD как метода решения ограничений и SoA как формата хранения данных.

  \item Разработана архитектура четырёхмодульного проекта (\texttt{compute/},
    \texttt{core/}, \texttt{scene/}, \texttt{bindings/}) с чётким разделением
    GPU-абстракции, физической логики и интерфейсного слоя.

  \item Реализован полный конвейер симуляционного шага:
    симплектический интегратор Эйлера,
    широкая фаза LBVH (алгоритм Карраса),
    узкая фаза с аналитическими тестами, SAT и GJK+EPA,
    XPBD-решатель контактов и сочленений.

  \item Реализована поддержка шарнирных цепочек (articulations)
    с четырьмя типами сочленений, угловыми упорами и PD-моторами.

  \item Разработана CI-инфраструктура с матрицей CUDA/HIP/CPU $\times$ Debug/Release
    и механизмом автоматической проверки детерминизма через золотой след.

  \item Достигнута производительность $\approx 4000$~fps на CPU для сцены
    с 7-звенным манипулятором при $\geq 67$-кратном превышении реального времени.
\end{enumerate}

Практическая значимость работы определяется тем, что разработанный движок:
\begin{itemize}
  \item независим от производителя GPU и работает на оборудовании NVIDIA и AMD;
  \item детерминирован побитово, что является обязательным условием
    для воспроизводимых экспериментов в обучении с подкреплением;
  \item предоставляет Python API с нулевым копированием данных через DLPack,
    совместимый с JAX/PyTorch-пайплайнами.
\end{itemize}

\textbf{Перспективы развития.}
К приоритетным направлениям дальнейшего развития относятся:
\begin{enumerate}
  \item Оптимизация параллельного XPBD-решателя с раскраской графа ограничений
    для GPU-параллелизма.
  \item Интеграция конвейера загрузки SDF/URDF (фаза~3) и поддержка
    полной трёхмерной сцены с мобильным манипулятором.
  \item Многопроцессорная симуляция (multi-GPU) с пространственной декомпозицией.
  \item Дифференцируемая физика (фаза~6): ленточный обратный режим AD
    над ядрами SYCL.
\end{enumerate}
