\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

В настоящей работе разработан физический движок \textit{dyphur}~--- библиотека симуляции твёрдых тел, 
вычисляемая на графическом процессоре средствами стандарта SYCL~2020.

В ходе работы решены следующие задачи:

\begin{enumerate}
  \item Проведён сравнительный анализ существующих систем физического моделирования
    (Bullet Physics, NVIDIA PhysX, MuJoCo, ODE, Rapier, NVIDIA Newton).
    Установлено, что ни одна из них не удовлетворяет совокупности требований:
    открытая лицензия, независимость от производителя графических процессоров, встраиваемый C++ API.

  \item Сформулированы требования к системе; обоснован выбор SYCL/AdaptiveCpp
    как вычислительного стека, XPBD как метода решения ограничений и SoA как формата данных.

  \item Разработана архитектура четырёхмодульного проекта (\texttt{compute/},
    \texttt{core/}, \texttt{scene/}, \texttt{bindings/}) с чётким разделением
    абстракции над графическим процессором, физической логики и интерфейсного слоя.

  \item Реализован полный конвейер симуляционного шага:
    симплектический интегратор Эйлера с подшагами,
    широкая фаза LBVH (алгоритм Карраса) с level-synchronized refit,
    параллельная узкая фаза (SAT, GJK+EPA),
    XPBD-решатель контактов и сочленений с раскраской графа.

  \item Реализована поддержка шарнирных цепочек (articulations)
    с четырьмя типами сочленений, угловыми упорами и PD-моторами;
    загрузка сцен из SDF/URDF через libsdformat с выпуклой декомпозицией V-HACD.

  \item Реализован API лучевых запросов на графическом процессоре (\texttt{ray\_query})
    и датчиков контактов (\texttt{ContactSensor}) с нулевым копированием
    данных через DLPack.

  \item Разработан инструмент визуализации \texttt{tools/viz/} на базе Magnum
    с тремя режимами: безголовый рендеринг EGL, интерактивный просмотр GLFW,
    потоковый режим через разделяемую память.

  \item Создана CI-инфраструктура с матрицей CUDA/HIP/ЦП $\times$ Debug/Release
    и автоматической проверкой детерминизма через золотой след.

  \item Достигнута производительность выше реального времени
    ($\geq 60$~Гц) для сцен до 8192 тел;
    графический процессор превосходит центральный при числе тел $\gtrsim 1000$
    (${\approx}233$~fps CUDA против ${\approx}206$~fps OpenMP).
\end{enumerate}

Интеграция \textit{dyphur} в платформу «Модейлер» позволит существенно расширить её возможности по нескольким 
направлениям. Во-первых, замена текущего решателя на центральном процессоре конвейером на графическом даст кратный прирост производительности 
при симуляции промышленных сцен~--- конвейеров, роботов-манипуляторов и взаимодействующих с ними объектов,~--- 
что критично для построения цифровых двойников в реальном времени. Во-вторых, побитовая детерминированность 
симуляции обеспечит воспроизводимость SIL-тестов управляющего программного обеспечения: один и тот же сценарий 
будет давать идентичный результат при каждом прогоне, что упрощает отладку и сертификацию систем управления. 
В-третьих, поддержка форматов SDF/URDF и Python API позволит использовать «Модейлер» как платформу для 
обучения робототехнических агентов с подкреплением~--- без перехода на сторонние симуляционные окружения.

Практическая значимость работы определяется следующим:

\begin{itemize}
  \item движок независим от производителя графических процессоров (NVIDIA и AMD через единый код);
  \item детерминирован побитово, что обязательно для воспроизводимых
    экспериментов в обучении с подкреплением;
  \item предоставляет Python API с нулевым копированием данных (DLPack),
    совместимый с JAX/PyTorch-пайплайнами.
\end{itemize}

\textbf{Перспективы развития.}
\begin{enumerate}
  \item Оптимизация BVH-построения и обхода (текущее второе по стоимости звено
    при $\gtrsim 4000$ тел).
  \item Поддержка нескольких графических процессоров с пространственной декомпозицией (Phase~4).
  \item Дифференцируемая физика: ленточный обратный режим AD над SoA-ядрами.
\end{enumerate}
